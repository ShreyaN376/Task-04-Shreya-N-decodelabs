GENERAL KNOWLEDEGE QUIZ

PROJECT OVERIVEW

The General Knowledge Quiz is a simple Python-based quiz application that asks the user a series of general knowledge questions and calculates the final score based on the answers provided.

OBJECTIVE:

The objective of this project is to practice:

Python input handling
if-else conditional statements
String manipulation using .strip() and .lower()
Score calculation
Basic control flow

FEATURES:

Displays general knowledge questions
Accepts answers from the user
Handles different forms of user input using .strip() and .lower()
Checks whether the answer is correct
Displays correct or incorrect feedback
Keeps track of the score
Displays the final score at the end

TECHNOLOGIES USED:

Python 3
Built-in Python functions and operators

HOW THE PROGRAM WORKS:

The program starts with a score of 0.
A general knowledge question is displayed.
The user enters an answer.
The answer is cleaned using .strip() and .lower().
The program checks the answer using an if-else condition.
If the answer is correct, the score is increased by 1.
The same process is repeated for each question.
At the end, the program displays the user's final score.
